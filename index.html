OPENROUTER_API_KEY (required) — your OpenRouter API key.
SYSTEM_PROMPT (optional) — overrides the built-in authority gate prompt. Use literal newlines (\n) in the TOML string.
ENVIRONMENT (optional) — shown in UI for info.
OPTIONAL_HTML_TITLE (optional) — page title.
OPTIONAL_PLAIN_TEXT_INTRO (optional) — prepended to the initial message if present.
